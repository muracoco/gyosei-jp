# 作成方法と検証記録

## 調査した文章

12道府県から4,871文書・245,885文を収集し、うち4,868文書を分析しました。見出しや段落の構成、語句の使い方、修飾、情報の順序などを調べています。対象は収集できた資料に限られ、全国の公的文章を代表する標本ではありません。

行政特有の傾向を見分けるため、比較用に次の3群を用意しました。

| 文章の種類 | 文書数 |
|---|---:|
| 行政の文章 | 2,472 |
| AIが生成した文章 | 1,000 |
| 行政以外の正式な文章 | 1,000 |

AIの文章は、原文から内容を整理した素材をもとに生成しました。原文の言い回しや見出しは渡していません。

## スキルへの反映

文書の種類や組織による違い、反例を調べ、推敲に使える判断を検討しました。202候補のうち、探索用とは別の評価資料でも確認できた構造上の操作は、次の2つです。

- 内容の区分が明確な文章に、その区分を示す見出しを付ける。
- 複数の内容が続く長い段落を、文の切れ目で分ける。

この2操作で確認したのは、本文の語句や文順を変えず、見出しや改行を加える使い方です。残る194候補は観測にとどめ、6候補は採用しませんでした。

語順、修飾、用語、文体などは、文脈に応じて選ぶ編集上の判断としてまとめました。判断の説明に改稿例や適用を控える場面を添え、報告・手順・案内など、用途別の組み立て方も盛り込んでいます。

## 検証の範囲

現行版は全文を読み直し、スキルのファイル形式と配布内容の一致を確認しています。スキル全体の文章改善率や、読者による評価は未測定です。

対象件数や採否の集計は [研究集計](research-summary.json) に載せています。自治体の原文や個別の生成結果は公開していません。
