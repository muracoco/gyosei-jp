# gyosei-jp

日本語の文章を、意味や語り口を保ちながら推敲するスキルです。

## 使い方

[SKILL.md](SKILL.md) を、AIツールのスキル保存先へ `gyosei-jp/SKILL.md` として置いてください。

```text
$gyosei-jp
次の文章を読みやすくしてください。

（本文）
```

「誤字だけ」「この段落だけ」といった指定や、素材からの執筆、文章の点検にも使えます。

## 作成の背景

自治体の公表文を調べて作りました。詳しくは [作成方法と検証記録](docs/methodology.md)、[研究集計](docs/research-summary.json) をご覧ください。自治体の原文は公開版に含めていません。
