# gyosei-jp

書いた文章が回りくどい、話がうまくつながらない。そんなときに使う、日本語の推敲スキルです。技術的な説明や仕事の文書、案内、FAQなどを想定しています。

たとえば、説明が重複している文は、次のように整理します。

改稿前：

> ここで、更新後の操作について説明します。更新後は、設定画面で通知先を変更できます。通知先を変更できる点が今回の変更点です。

改稿後：

> 更新後は、設定画面で通知先を変更できます。

言葉を省くときも、数字や条件は残します。「予定」を「決定」に変えたり、原文にない理由を足したりしないよう、書き直した文を原文と照合します。書き手の口調や、意図のある繰り返しも文脈を見て扱います。

## 使い方

必要なのは [SKILL.md](SKILL.md) だけです。利用するAIツールのスキル保存先に、`gyosei-jp/SKILL.md` として置いてください。外部ツールの導入や研究データの読み込みは不要です。

スキル名を指定できるツールでは、次のように文章を添えて依頼します。

```text
$gyosei-jp
次の文章を、意味を変えず読みやすくしてください。
完成文だけ返してください。

（ここに原文）
```

「誤字だけ直して」「この段落だけ」と、直す範囲を指定できます。読み手や用途、長さ、残したい口調が決まっていれば、一緒に伝えてください。

文章を作るときは「この素材から案内文を書いて」、点検したいときは「気になる箇所と修正案を挙げて」と依頼してください。点検では原文を書き換えず、指摘と修正案を返します。

出力された文章は、使う前に内容を確認してください。

## 作成の背景

自治体が公表した文章を調べ、日本語の書き直し方をまとめました。調査の進め方と検証結果は [作成方法と検証記録](docs/methodology.md)、対象件数などの集計は [研究集計](docs/research-summary.json) に載せています。現行版でどれだけ文章が改善するか、ほかのスキルと比べてどうかは、まだ測定していません。

自治体から取得した本文や個別のモデル出力は、このリポジトリに含めていません。例文は、書き直し方を説明するために作ったものです。
