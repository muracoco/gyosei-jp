# gyosei-jp

言い回しや文の構成を整える、日本語の推敲スキルです。説明文、案内、仕事の文書などに使えます。

回りくどい表現や長い修飾を見直し、話がつながりにくいところは文の順序や段落から組み直します。長文では、見出しや節の並びも含めて推敲します。

たとえば、開催情報と申込情報が混ざった案内なら、次のようにまとめます。

改稿前：

> 研修は6月10日です。申込締切は6月3日です。研修はオンラインで行います。申込先は研修窓口です。

改稿後：

> 研修は6月10日にオンラインで行います。
>
> 申込締切は6月3日、申込先は研修窓口です。

## 導入

Codexで使う場合は、[SKILL.md](SKILL.md) を次の場所へ置きます。使うために必要なのは、この1ファイルだけです。

| 使う範囲 | 保存先 |
|---|---|
| 自分のすべてのプロジェクト | `~/.agents/skills/gyosei-jp/SKILL.md` |
| 特定のプロジェクト | `<プロジェクト>/.agents/skills/gyosei-jp/SKILL.md` |

Windowsの `~` はユーザーフォルダです。エクスプローラーで `%USERPROFILE%` を開き、その下に `.agents/skills/gyosei-jp` を作って配置できます。すでに同名のスキルがある場合は、使う版を1つに揃えてください。

配置後、Codexでスキル名を選択します。CLI・IDE拡張では `$gyosei-jp` と入力して呼び出せます。反映されない場合はCodexを再起動してください。保存先や呼び出し方の詳細は [Codex公式のスキル説明](https://learn.chatgpt.com/docs/build-skills) を参照してください。

ほかのAIツールでは、そのツールのスキル導入手順に従ってください。更新するときは `SKILL.md` を差し替えます。

## 使い方

```text
$gyosei-jp
次の文章を読みやすくしてください。

（本文）
```

「もう少しくだけた口調で」「誤字だけ」「この段落だけ」など、用途や直す範囲も指定できます。

素材から文章を作りたいときは「このメモから案内文を書いて」、気になる箇所を知りたいときは「読みにくい箇所と修正案を挙げて」と依頼してください。

| やりたいこと | 依頼例 |
|---|---|
| 作成 | このメモから、参加者向けの案内文を作ってください。 |
| 改稿 | この報告を、結論と次の対応が分かるように整えてください。 |
| 点検 | 全文は書き換えず、説明が食い違っている箇所を指摘してください。 |

案内、報告、技術説明などの [6つの使用例](docs/examples.md) を用意しています。

## 試す・改善する

[評価用の入力](docs/evaluation-cases.json) と [確認手順・試行記録](docs/evaluation.md) を公開しています。正解文との完全一致ではなく、依頼した編集になっているかを確認します。

改善案や不具合は [Issues](https://github.com/muracoco/gyosei-jp/issues) へお寄せください。依頼文、問題のある出力、期待した結果があると確認しやすくなります。実際の業務文や個人情報は載せず、問題を再現できる作例へ置き換えてください。文章や使用例の修正はPull Requestでも受け付けています。

## 作成の背景

自治体の公表文、一般の文章、AIの出力を比べ、文章の組み立てや言い回しの傾向を調べて作りました。調査や検証については [作成方法と検証記録](docs/methodology.md)、[研究集計](docs/research-summary.json) をご覧ください。

自治体の原文は公開版に含めていません。上の例文は、書き直し方を示すための作例です。
