# gyosei-jp

意味や条件を守りながら、日本語の文章を読みやすくするSkillです。文章の作成、改稿、点検に使えます。

**使うファイルは [SKILL.md](SKILL.md) 一つです。** 外部ツールや研究データの読み込みは必要ありません。

## できること

- 要点が伝わる順序に並べ、段落や文のつながりを整える
- 主語と述語のねじれ、長い修飾、回りくどい表現を直す
- 数値、条件、例外、確度、書き手の語り口を保つ
- 報告、手順、案内、FAQなど、用途に合った文章を組み立てる
- 点検だけの依頼では、問題箇所と修正案を示す

公的文章の研究を出発点にしています。技術説明や一般の業務文にも使えます。

## 導入

[SKILL.md](SKILL.md) を取得し、利用するAIツールのSkill保存先へ `gyosei-jp/SKILL.md` として配置してください。対応するツールでは、Skill名を指定して呼び出します。

```text
$gyosei-jp
次の文章を、意味を変えず読みやすくしてください。
完成文だけ返してください。

（ここに原文）
```

作成や点検も依頼できます。

```text
この素材から、利用者向けの案内文を作成してください。
```

```text
この文章を点検し、誤読につながる箇所と修正案を示してください。
```

読み手、用途、長さ、残したい語り口が決まっていれば、一緒に伝えてください。誤字だけの修正や、指定部分だけの改稿にも対応します。

## 作成方法と検証

調査の進め方、採用した判断、検証の範囲は、別添の [作成方法と検証記録](docs/methodology.md) にまとめています。[研究集計](docs/research-summary.json) には、対象件数と根拠資料の識別情報を載せています。

自治体の取得本文、原文データ、個別のモデル出力は、この公開版に含めません。本文中の例文は、編集の判断を説明するための作例です。

AIの出力は利用者が確認してください。現行版の一般的な文章改善率や、他のSkillに対する優位性は未測定です。
